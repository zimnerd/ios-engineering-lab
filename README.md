# iOS Engineering Lab

Practical Swift and native iOS engineering exercises, built to develop and demonstrate independent technical competence.

## Purpose

This repository contains my hands-on development work as I expand my native iOS expertise alongside my existing enterprise web and backend engineering experience.

Learning progress, assessments and mastery verification are centrally managed in [Engineering Growth](https://github.com/zimnerd/engineering-growth).

## Development Approach

- Implement concepts independently before requesting AI-generated solutions.
- Use AI for explanations, progressive hints and code review.
- Verify implementations through compilation, execution and tests.
- Document important engineering decisions and misconceptions.
- Link completed exercises to their corresponding learning objectives.

## Technical Direction

**Swift fundamentals:** Value/reference semantics, protocols, generics, error handling and concurrency.

**Native iOS:** SwiftUI, Observation, navigation, persistence, networking and application architecture.

**Engineering practices:** Unit testing, modularity, performance, security and CI/CD.

## Repository Organisation

Initial language exercises will use Swift Package Manager for reproducible execution.

Native iOS applications will be introduced separately when learning objectives require an application lifecycle, simulator or device capabilities.
